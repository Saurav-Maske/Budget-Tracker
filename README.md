# Budget Tracker

## Overview
A personal budget tracking application built with React, Node.js/Express, and PostgreSQL.

## Tech Stack
- **Frontend**: React (via create-react-app)
- **Backend**: Node.js with Express
- **Database**: PostgreSQL
- **Package Managers**:
